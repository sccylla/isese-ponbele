Important practice note

The direct-answer layer is a software interpretation system built around the cast and question topic. It is not a replacement for lineage-specific Ibọ̀, ẹbọ, Ese Ifá or the judgment of a trained Babaláwo. You can always use “Enter physical cast” to make the software interpret a real Opele throw.

WHAT CHANGED

This is now a consultation engine, not only an Odù lookup.

The app classifies the question, reads both principal legs, calculates a digital orientation for direct questions, and composes a matter-specific answer with supporting factors, obstacles and a practical next step. The Android edition also carries an expanded offline interpretation pack so it can work without internet.
