# Digital Opele Ifa
Web app: `/opele/` · Android source: `/opele-android/`

Casting convention: single mark = 1, double mark = 0, top-to-bottom, right leg named first. Eight binary Opele faces resolve into two four-bit legs and one of 256 Odù. The app also accepts a physical Opele throw for identification.

The `Build Digital Opele APK` GitHub Action creates an installable debug APK as a workflow artifact.
