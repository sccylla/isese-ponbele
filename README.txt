ISESE PONBELE — YORUBA ISESE, ORISA & CULTURAL ARCHIVE

A static multi-page HTML/CSS/JavaScript website designed as a rich public-facing Yoruba traditional knowledge house.

MAIN FILES
- index.html — immersive homepage with Babalawo/Ifa, cowries, Orisa and cultural photography
- catalogue.html — searchable Oogun archive demo
- knowledge.html — Ori, Ayanmo, Oogun, Orisa and cultural knowledge library
- herbs.html — searchable Ewe / plant reference
- about.html — purpose and archive structure
- contact.html — guided consultation form UI
- script.js — interactions, filters, modal, counters and form steps
- styles.css — imports the six ordered CSS design modules
- vercel.json — Vercel static-site configuration
- PHOTO-CREDITS.txt — cultural photo attribution and licence notes

DEPLOYMENT
This repository is ready for a static Vercel deployment. No build command or framework is required.

IMPORTANT
The consultation form is currently front-end only. Connect it to WhatsApp, email, a form provider, or a backend before relying on it for actual submissions.

CULTURAL IMAGERY
Selected cultural photographs are referenced from Wikimedia Commons. Keep PHOTO-CREDITS.txt with the project and preserve required attribution.
